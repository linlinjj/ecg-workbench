## 自己复查的顺序

1. 运行 `npm test`，再运行 `python -m pytest -q`，最后 `npm run build`。
2. 按 README 启动本地版，导入 CSV 模板和一条 WFDB 记录。
3. 添加心搏点、移动位置、写备注；添加区间并修改边界；检查撤销与重做。
4. 改变滤波、缩放与通道，确认标注采样索引保持不变。
5. 下载 CSV、PNG 和项目包；在另一次会话打开项目包，对照数据、标注和参数。
6. 模拟空值、非法频率、损坏项目和过短信号，检查明确错误提示。
