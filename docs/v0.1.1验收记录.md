## 修复与回归覆盖

| 问题 | 修改后的行为与检查 |
|---|---|
| 缺失来源或字段类型错误导致页面报错 | 后端与前端分别验证记录、通道、来源及参考标注；异常项目拒绝，现有记录和标注保留。缺省 reference 的合法旧项目恢复为空数组。 |
| 整体拖动区间越界后缩短 | 对共同位移限幅，左右边界保持长度；自动回归覆盖两端，真实浏览器将 `[200,600)` 拖为 `[0,400)`。 |
| 排他终点只能到 N−1 | 区间边界允许 N，点限制在 N−1；真实浏览器实际将区间终点拖至 21600。偏离拖柄中心抓取后拖出绘图区也有回归覆盖。 |
| 松开时读取过期预览 | 按 pointerup 最终坐标计算提交，测试中的最终坐标刻意不同于最后预览。 |
| 慢速保存误清新编辑状态 | 按项目身份／修订号确认快照；模拟延迟哈希期间继续编辑、切换新记录后编辑，以及导出失败。 |
| 导入、示例切换和首次加载竞态 | 统一请求版本控制并取消旧请求；模拟导入先完成、旧成功或错误晚返回，以及首次失败重试。加载中暂停编辑，失败保留旧内容。 |
| 真实浏览器补查 | 另修复选中标注拖动命中区域被画成粗线，以及 375 px 下两列滤波面板过窄的问题。 |

- Windows 沙箱出现过 realpath／临时文件 EPERM，未把未执行或超时的运行计为通过；正常本机权限下已重新执行并通过。

## 实际浏览器操作

在应用内浏览器打开本机生产版，执行并观察了以下结果：

1. 1440 px 桌面检查波形、坐标、概览、参考符号和两个侧栏；实际拖选区间、输入位置、拖动边界和整体移动。
2. 实际下载完整 `.ecgwork`，重新打开；之后再次导出并恢复包含 `[720,1440)` 区间、1080 点心搏、中文备注、高通 0.5 Hz 和当前视图的完整项目。
3. 实际下载 CSV，核对个人区间 720/1440、心搏 1080、来源偏移及独立参考标注行。
4. 实际导入 CSV 模板，得到 1800 点、360 Hz、单通道、5 秒波形。
5. 实际选择 MIT-BIH 100 的 `.hea + .dat + .atr` 三文件，得到 650000 点、360 Hz、2 通道、约 1806 秒和 2274 条参考标注；原公开数据文件只读。
6. 实际选择滤波预设，下载 **1676×932 RGBA PNG**；视觉检查原始／处理后曲线、2—4 秒区间、3 秒心搏点、中文标签、参考符号、坐标、单位及参数标题，无明显裁切。导出证据随补丁版附上 [waveform-export.png](https://github.com/linlinjj/ecg-workbench/releases/download/v0.1.1/waveform-export.png)。
7. 375 px 实际窄屏检查：页面没有横向溢出；波形工具条可横向滚动，滤波／详情在最终样式中改为单列，预设与 PNG 按钮完整显示。
8. 实际导入哈希正确但缺失来源的异常项目，页面显示“数据来源必须是对象”；关闭对话框后原两条标注保留，仍能继续缩放操作。

独立 Chrome、Edge 的完整兼容性，以及慢网／断网下 Pyodide 冷启动体验仍未单独实测，不能标记为通过。首次加载失败与请求竞态由受控自动化测试覆盖。

## 源码包与发布验收

发行源码包排除 Git 元数据、node_modules、虚拟环境、缓存、本机验收数据和发布凭据，包含内置 SHA256SUMS.json 及独立 ZIP SHA-256 文件。打包脚本核对 CRC 和每个解压文件的哈希。

独立解压目录重新安装锁定 npm 依赖，并新建 Python 虚拟环境安装锁定依赖；前端 33 项、Python 24 项、生产构建与 `pip check` 均通过。测试工具修补后的最终锁文件也在该副本重新安装与复验。对应提交的 CI、Pages、线上文件哈希核对记录见 [v0.1.1 发布页](https://github.com/linlinjj/ecg-workbench/releases/tag/v0.1.1)，只有远端两条工作流均成功才发布。

复现命令见 README；科学对照用 `npm run test:wasm`，本机 HTTP 用 `.venv/Scripts/python scripts/verify_local.py`，源码打包用 `.venv/Scripts/python scripts/package_release.py`。
