# 数据、格式与计算约定（v1）

## 核心数据

记录包含 id、name、fs、sampleCount、channels（name/unit/data）、reference（sample/symbol/note）与 provenance。每个通道长度一致，输入为有限数值。sampleCount×通道数不超过 500 万。

数值单位原样保留，不自动把 uV 当成 mV。时间轴用 sample/fs；原始记录中的位置用 provenance.offsetSamples+sample。导出 CSV 同时保留本地采样索引与原始偏移。

个人标注：id、kind（point/interval）、channel、start、可选 end、label、note。start 是整数；区间为 [start,end)，end 不包含在区间内，允许等于 sampleCount。参考符号不自动合并为人工 N/S/V 类别，保留原始含义。

## 项目包

扩展名 `.ecgwork`，内容是 ZIP：

- record.json：原始数值波形、单位、参考标注与来源。
- manifest.json：format=`ecg-workbench`，version=1；recordSha256；annotations、settings、channel、view、savedAt。

先校验格式与数据哈希，再验证通道、标注和视图范围。仅接受这两个条目；拒绝重复项、未知版本、过大解压体积、非法采样值与越界标注。恢复后从原始数据重算滤波结果。

## 滤波

共享实现只有一份：`public/python/dsp.py`。线上 Pyodide 314.0.7 / SciPy 1.18.0；本地 SciPy 同为 1.18.0。固定依赖见锁文件。

开启的滤波器组合成二阶节（SOS），最后对完整通道调用 `sosfiltfilt`：

1. 高通：Butterworth，原型二阶，默认 0.5 Hz。
2. 低通：Butterworth，原型四阶，默认 40 Hz。
3. 陷波：iirnotch，50 或 60 Hz，Q=30，再转 SOS。

双向处理会改变最终频率响应与有效阶数；这些预设仅用于教学探索，不是临床采集规范。至少需要 3 秒且不少于 64 点，所有启用频率严格小于 Nyquist，且高通频率低于低通。原始信号默认不处理。记录边缘可能出现边界效应。

显示抽样仅用于渲染：每个桶保留原始与处理后信号的最小、最大值及首点。标注始终使用完整原始索引，不对抽样数组定位。图像导出使用当前视图，数据导出使用完整数据。

## 本地接口

仅绑定 127.0.0.1，同源访问；不提供云端上传服务。

- GET `/api/health`：mode=local、version。
- POST `/api/filter`：JSON samples、fs、settings；返回 samples。频率或信号非法时返回 400。
- POST `/api/import`：multipart files；CSV 另有 fs、unit；返回规范化 record，项目包另返回 annotations/settings/channel/view。格式错误返回 400，超过文件限额返回 413。
- GET `/api/docs`：接口说明。

浏览器通过请求版本号丢弃过期计算结果，切换记录与通道后不接受之前的计算覆盖。滤波错误时显示错误与重试，保留原始波形供查看。
